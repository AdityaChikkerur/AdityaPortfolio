# Aditya Chikkerur Portfolio

Static portfolio with a neo-brutalist visual system.

### Latest updates
- Opening voyage animation: a stylized ship sails in, crashes into the shore, and the pirate jumps from the deck.
- No skip button; the intro plays automatically and then reveals the portfolio.
- Fixed the hanging pirate rope so it starts at the ceiling pin and reaches the pirate's hat.
- Kept the home hero portrait and typing animation.
- GitHub and LinkedIn links use the official brand-style SVG marks.
- Included `favicon.svg`.

Open `index.html` directly or serve the folder with any static web server.


## Animation behavior
- The opening screen is a ship-only sequence: the ship sails in, hits the shore, rocks on impact, creates a splash, and exits automatically.
- The pirate is NOT part of the opening animation. It remains the separate hanging page decoration after the intro.
- The home screen starts its own entrance animation after the opening sequence: content rises in, the portrait scene enters, skill cards appear, and the name types in.
